## libarchive RAR5 reader (reference for the RAR5 compression algorithm)

RARLAB's public technical note describes the RAR5 container but not its compression algorithm. `src/Unpakz.Core/Rar/Rar5Decoder.cs`
re-implements the algorithm (Huffman table layout and construction, symbol / length / distance coding, repeat-distance cache and the
delta / x86 / ARM filters) following the behaviour of libarchive's `archive_read_support_format_rar5.c`. The code in this repository is
our own structure (streaming window that grows on demand, exhaustive bounds checking, filters as pure functions, solid-group handling)
and is verified against RARLAB's own `rar` and `unrar` binaries, not against libarchive.
